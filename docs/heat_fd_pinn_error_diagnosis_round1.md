| `mean_abs_error` | `0.14373303814773725` |

| `max_relative_l2_error_over_time` | `0.6751864182885009` |

误差不是只在初始时刻偏大。`t = 0` 的相对误差约为 `0.1021`，`t = 2.5` 已升至约 `0.6432`，最大值出现在最后一个时间点 `t = 5`，为约 `0.6752`。这说明当前问题主要体现在频域系数的时间演化没有跟上参考解，而不只是 `irFFT` 后的初始重构存在轻微偏差。

## 频域误差集中位置

按整个 `t-x` 网格上的频域误差能量贡献排序，误差高度集中在低频模式：

| Mode | Contribution |
| --- | --- |
| `2` | `0.47981040230557676` |
| `3` | `0.24569742777137785` |
| `4` | `0.15683352132901354` |
| `5` | `0.10386768978063231` |

mode `2` 到 mode `5` 的贡献合计约为 `98.62%`。mode `1` 与 mode `8` 分别只贡献约 `0.65%`，其余模式贡献更小。这个分布不符合“所有 mode 被统一放大或缩小”的尺度错误特征，更像是少数低频模式的频域 ODE 拟合失败后主导了全局误差。

## `t = 0` 初值拟合

`t = 0` 的初值拟合并不充分，但不是所有低频模式都坏掉：

- 零频 mode `0` 对齐很好，绝对频谱误差约为 `2.60e-09`，没有看到零频异常。
- mode `1`、mode `2`、mode `3` 在 `t = 0` 的相对频谱误差分别约为 `0.00061`、`0.00248`、`0.00661`，这些最前面的低频 mode 初值基本对齐。
- mode `4` 在 `t = 0` 的相对频谱误差约为 `0.1348`，mode `5` 约为 `0.2756`，初始拟合已经出现明显缺口。
- 若按 mode `0` 到 mode `4` 统计，前 `5` 个 mode 只贡献 `t = 0` 频谱误差的约 `18.50%`。`t = 0` 的主要误差来自 mode `5`、mode `11`、mode `4` 与 mode `15`，其中 mode `5` 单独贡献约 `51.80%`。

因此，初值损失没有完全压到足够低，但问题不是零频错误，也不是最前面几个低频 mode 全部未对齐。

## `t = 5` 末态误差

末态表现更清楚地说明当前误差由低频残留主导：

- `t = 5` 时，参考解在 mode `50` 及以上的幅值占比约为 `6.78e-16`，高频已经被热方程耗散到可忽略。
- mode `0` 仍然对齐，零频绝对频谱误差约为 `2.59e-09`。
- mode `0` 到 mode `4` 已贡献末态频谱误差的约 `81.86%`。
- 末态 top error modes 依次是 mode `2`、mode `4`、mode `5`、mode `3`、mode `1`。把 mode `5` 也计入后，低频 mode `1` 到 mode `5` 几乎覆盖全部末态频谱误差。

具体看末态幅值，mode `2` 和 mode `3` 的预测幅值几乎衰到零，但参考幅值仍分别约为 `21.84` 与 `10.30`；mode `4` 和 mode `5` 则保留了过大的预测幅值。当前主要偏差是低频模式演化曲线没学对，不是末态还残留一大片高频噪声。

## 诊断结论

当前误差更不像 `FFT/irFFT` 尺度问题。

理由是：

1. 零频 mode `0` 在 `t = 0` 和 `t = 5` 都精确对齐。
2. mode `1` 到 mode `3` 的初始频谱也基本对齐。
3. 总误差集中在少数 mode，尤其 mode `2` 到 mode `5`，而不是所有频率呈统一比例偏差。
4. 热方程末态的高频参考幅值已经自然耗散，末态误差仍由低频控制。

在给定候选里，当前结果更像是 **低频模式训练/优化尚未充分完成，并且现有初值损失与残差损失没有把这些模式的时间演化同时压好**。这和已有训练历史也一致：最终 `final_initial_loss = 0.6836130951941308`、`final_residual_loss = 1.8952208222139717` 都没有接近零，最优总损失还停在第 `25` 步附近。

现阶段还没有足够证据优先归咎于网络结构。论文热传导设置本来就是 `3` 个 hidden layers、每层 `5` 个 neurons；当前更早应检查每个低频 mode 的损失尺度、残差拟合状态与 `L-BFGS` 优化停滞情况。损失权重是否需要调整是后续可验证的怀疑点，但本轮只读诊断还不能把它定性成唯一原因。

## 下一步建议

下一步建议仍保持小步诊断，不直接调参：

1. 针对 mode `2` 到 mode `5` 单独检查初值误差、残差误差和预测频谱随时间的曲线，确认是哪几个 mode 先偏离参考衰减轨迹。
2. 在后续受控实验中记录逐 mode 的训练损失，而不是只看当前跨 mode 平均历史，避免低频失败被聚合指标遮住。
3. 若逐 mode 诊断确认低频初值与残差约束拉扯，再评估损失尺度或 `L-BFGS` 配置差异；在此之前不要把问题直接归因为网络容量。
