# Heat FD-PINN m50 s500 结果报告

## 实验设置

本次实验按当前热传导 `FD-PINN` 训练脚本的论文口径参数运行：

- `modes = 50`
- `steps = 500`
- `num_residual = 200`
- 输入为时间 `t`
- 每个非负频率模式使用一个独立小网络
- 每个网络包含 `3` 个 hidden layers，每层 `5` 个 neurons
- 每个网络输出 `real(u_hat_m)` 与 `imag(u_hat_m)`
- 优化器为 `L-BFGS`，`max_iter = 3`
- `seed = 1234`
- 设备为 `cpu`

uv run python -m scripts.train_heat_fd_pinn --modes 50 --steps 500 --num-residual 200 --output-dir outputs/heat_fd_pinn_m50_s500

## 收敛判断

训练流程正常完成，`training_history.csv` 记录了完整的 `500` 个外层 step，损失、预测数组与指标均保持有限。

损失从第 `1` 步的 `60.153142691678696` 降至最终的 `2.5788339174081027`，说明训练链路确实发生了优化。需要注意的是，本次历史中最小训练损失出现在第 `25` 步，为 `2.3201443473009045`；之后损失在更高水平附近缓慢变化，最终误差仍为 `0.539048283904845`。因此可以说本次实验稳定跑完并完成了损失下降，但还不能据此认定已经达到论文精度口径下的良好收敛。

## 与 smoke test 的区别

smoke test 只验证脚本闭环：

- `modes = 3`
- `steps = 2`
- `num_residual = 5`
- 输出目录为 `outputs/heat_fd_pinn_smoke`

本次正式实验则使用论文热传导 `FD-PINN` 设置中的 `50` 个模式、`500` 个外层 step 和 `200` 个残差采样点。正式实验重构了更多频率成分，并提供了完整长度的训练历史。两次实验的训练损失不宜直接横向比较，因为模式数与残差采样规模不同；相对误差可作为当前脚本状态下的参考，smoke test 为约 `0.6182`，本次正式实验为约 `0.5390`。

`prediction.npz` 已保留 `x`、`t`、`u_pred` 与 `u_ref`，后续若进入结果可视化阶段，可以在不重新训练的前提下基于该文件生成误差图。

## 当前误差偏高的可能原因

本轮没有为了降低误差临时调参，也没有修改 solver。基于当前输出，后续排查可优先关注这些差异：

1. 当前最小实现对各频率模式和损失项采用了直接平均，论文中损失权重、频谱尺度处理或模式训练细节未在当前脚本中进一步校准。
2. 当前脚本只固定一批随机残差采样点，采样策略与论文实现可能不同。
3. 当前 `L-BFGS` 设置只对齐了 `max_iter = 3`，其他实现细节、线搜索行为和停止状态可能与论文代码不同。
4. 当前结果只有训练损失历史，尚未建立论文图 4 使用的误差随 step 变化诊断，因此还不能确认误差主要受优化停滞、损失尺度还是重构阶段影响。

下一步应先围绕这些差异做诊断和结果对齐，再决定是否需要最小修正训练实现。
